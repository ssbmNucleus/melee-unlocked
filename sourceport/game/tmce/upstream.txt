# Training Mode CE upstream: the commit the native build compiles. The game's build fetches it
# (that commit alone) and tools/tmce/prepare_src.py makes the native source from it: its src/
# files, tools/tmce/native_edits.py, tools/tmce/native_fixes.patch. tools/tmce/gen_mextk.py reads
# its MexTK/ headers.
#
# src-sha256 is the hash of the src/ files the build takes. asm-sha256 is the hash of the whole
# ASM/ folder: TM-CE's assembly patches, which the native hooks port by hand. A new commit whose
# ASM/ differs fails the build until its changes are ported and the new hash is recorded here.
# dats-sha256 is the hash of the dats/ files the game loads from TM/ beside it (the event menu's,
# the Lab's, its character select's, the wavedash drill's): the build writes them from the commit
# (prepare_src.py --dats) only when they match. They are build outputs, never committed.
# `python tools/tmce/prepare_src.py --upstream <dir> --hashes` prints the values.
